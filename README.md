# smoothbrainttt.github.io

This repository hosts a single-file, single-page website for the SmoothBrain TTT project. The site is served via GitHub Pages.

Live site: https://themrfailz.github.io/smoothbrainttt.github.io/

Editing
- Modify `index.html` and push changes to the `main` branch to update the site.
- Preview locally by opening `index.html` in a browser or using a static server like `python -m http.server`.
